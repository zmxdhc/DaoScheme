# DaoScheme

DaoScheme is a schema-driven, real-time-processing engine for distributed, dynamic data management and decentralized application workflows.

DaoScheme is built to be simple and practical, focusing on doing one thing well.

**Why DaoScheme?**

- DaoScheme is a schema-driven, real-time-processing
- engine for distributed, dynamic data
- management and decentralized application workflows

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoScheme.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DaoScheme, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
